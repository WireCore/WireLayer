# @wirecore/wirelayer-tokens

Design tokens of WireLayer – colors, radii, typography, size grid, local fonts and themes – as a Tailwind CSS v4 theme and as TypeScript for React Native.

[Storybook](https://wirecore.github.io/WireLayer/) · [GitHub](https://github.com/WireCore/WireLayer) · [Changelog](./CHANGELOG.md)

## Installation

```sh
pnpm add @wirecore/wirelayer-tokens
```

## Usage

```css
@import 'tailwindcss';
@import '@wirecore/wirelayer-tokens/theme.css';
@import '@wirecore/wirelayer-tokens/fonts.css';
```

Usually you do not install it directly: `@wirecore/wirelayer-vue`, `-react`, `-native` and `-css` bring it with them.

Part of [WireLayer](https://github.com/WireCore/WireLayer) – one look and one API for Vue, React, React Native and HTML, accessible according to WCAG 2.2 AA.
