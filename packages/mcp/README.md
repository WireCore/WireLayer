# @wirecore/wirelayer-mcp

MCP server with the WireLayer component API (props, events, slots of every component) and the guides, for AI assistants such as Claude Code. The same content is published as [llms.txt](https://wirecore.github.io/WireLayer/llms.txt).

[Storybook](https://wirecore.github.io/WireLayer/) · [GitHub](https://github.com/WireCore/WireLayer) · [Changelog](./CHANGELOG.md)

## Installation

```sh
claude mcp add wirelayer -- npx -y -p @wirecore/wirelayer-mcp wirelayer-mcp
```

## Usage

Tools: `list_components`, `get_component`, `search_components`, `get_guide`. Any MCP client works: run the command `wirelayer-mcp` (stdio) from the package `@wirecore/wirelayer-mcp`.

Part of [WireLayer](https://github.com/WireCore/WireLayer) – one look and one API for Vue, React, React Native and HTML, accessible according to WCAG 2.2 AA.
