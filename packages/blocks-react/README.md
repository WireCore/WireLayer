# @wirecore/wirelayer-blocks-react

Page blocks for React built on `@wirecore/wirelayer-react`: SiteHeader, CtaSection, ModeToggle, AuthForm, AuthLayout and the ConditionBuilder (nested AND/OR rules, also the editor of the DataTable's advanced filter).

[Storybook](https://wirecore.github.io/WireLayer/) · [GitHub](https://github.com/WireCore/WireLayer) · [Changelog](./CHANGELOG.md)

## Installation

```sh
pnpm add @wirecore/wirelayer-blocks-react @wirecore/wirelayer-react
```

## Usage

```tsx
import { ConditionBuilder } from '@wirecore/wirelayer-blocks-react';
```

Part of [WireLayer](https://github.com/WireCore/WireLayer) – one look and one API for Vue, React, React Native and HTML, accessible according to WCAG 2.2 AA.
