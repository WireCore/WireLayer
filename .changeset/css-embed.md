`wirelayer-css embed`: WireLayer inside a page that brings its own CSS (WordPress admin, a host app) – the chosen components in one file, scoped to one element (`--scope '#my-app'`), without `@layer`, with the fonts. The parts come precompiled in `dist/embed/`, no build tools needed. `wirecore.css` and `components.css` stay unchanged.
